# 🕵️ Boîte Noire - Application de Cryptage de Messages

**Boîte Noire** est une application Windows développée en **C#** permettant de **crypter et décrypter des messages** en toute simplicité à l'aide d'une **clé secrète personnalisée**.  
Chaque utilisateur peut définir sa propre clé, assurant que seul celui qui connaît cette clé puisse lire les messages.

---

## ✨ Fonctionnalités

- 🔐 Cryptage et décryptage de texte avec une clé secrète
- 🧠 Algorithme XOR + Base64 simple pour usage pédagogique
- 🔑 Zone dédiée à la saisie de la clé de cryptage
- 👁‍🗨 Bouton pour afficher/masquer la clé de cryptage
- 📊 Progress bar visuelle lors des opérations
- 🧱 Interface fixe, propre et intuitive
